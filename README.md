# Physical Access Control Barrier

## Overview
A physical security logic system developed for ENSC 1412. This project models an automated barrier system designed to regulate and restrict physical access using state-machine logic.

## Architecture & Capabilities
* **State Operations:** Hardcoded logic defining strict 'Open', 'Closed', and 'Fail' states.
* **Hardware Interface:** Managing the physical deployment mechanisms of the barrier system.
* **Access Regulation:** Translating authorized inputs into kinetic movement while blocking unauthorized physical entry.
